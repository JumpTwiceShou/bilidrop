# BiliDrop v2.0.1 紧急更新说明

v2.0.1 修复 Bilibili 活动页格式变化造成的当天任务识别失效。建议所有 v2.0.0
用户尽快更新。

## 修复内容

- 兼容 Bilibili 最新的压缩 JavaScript 活动页数据，同时继续兼容旧版标准 JSON 页面。
- 按任务标注的开始和结束时间选择当前生效任务，不再把昨天已经结束的任务当成今天任务。
- 恢复当天全部任务 ID 的识别，使当前观看进度、完成节点和自动领取重新查询正确任务。
- 后台自动挂机发现旧任务已经结束时，会清除旧进度并停止由后台模式启动的旧心跳，
  然后继续定时寻找当天新任务。
- 保留 `/x/task/totalv2` 浏览器网络捕获兜底；Bilibili 首页产生的无关请求不再导致
  浏览器提前关闭。
- 可见浏览器兜底最多等待 2 分钟：识别成功立即关闭，超时自动关闭并明确提示失败。
- 默认在启动后静默检查一次 GitHub 最新 Release，可在“设置与日志 → 高级设置 →
  桌面运行”关闭。发现新版本时只询问是否打开 Release 页面，不会自动下载或安装。

## 验证

- 使用守望先锋电竞直播间 `23612045` 的实时公开页面验证，程序能够从 5 个日期任务组中
  选择当前 DAY2，而不是已经结束的 DAY1。
- 当前任务有效时间识别为 2026-07-30 17:30 至 2026-07-31 17:00（北京时间）。
- 标准 JSON 页面、最新压缩页面、跨日过期保护、后台自动挂机清理和浏览器兜底均有
  自动化回归测试。

## 升级方法

1. 从 [GitHub Releases](https://github.com/JumpTwiceShou/bilidrop/releases/latest)
   下载 v2.0.1 单文件 EXE。
2. 从托盘完全退出正在运行的旧版本。
3. 运行新 EXE；已保存账号和设置仍从 `%LOCALAPPDATA%\BiliDrop` 读取，无需重新迁移。

本次更新不改变账号、Cookie 和设置的存储格式。
