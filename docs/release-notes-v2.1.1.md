# BiliDrop v2.1.1 更新说明

2026-10-03 · Windows x64 单文件版

基于 v2.1.0 的兼容性与稳定性修复，保留持续任务监测、多账号独立设置和并发控制等现有功能。

## 更新内容

- **增强任务 ID 获取兼容性**：支持更多活动页面，减少对浏览器的依赖，仅在必要时启用浏览器辅助获取。
- **优化有效任务识别**：改善跨日期任务切换，避免选中已结束、未开始或其他直播间的任务。
- **修复挂机提前停止问题**：避免进度获取异常时误判全部任务已完成。
- **修复奖励状态显示异常**：改善领取结果判断，避免错误显示“已领取”，并支持领取失败后重试。
- **提升多账号切换稳定性**：防止切换账号或修改 Cookie 后，旧账号的任务结果影响当前账号。
- **增强账号保存可靠性**：保存失败时保留原有数据，改善部分账号数据异常时的恢复处理。
- **优化取消与退出操作**：修复取消后结果仍写回、切换任务后旧操作干扰新任务，以及退出时后台任务未正确停止的问题。
- **修复部分环境下的程序启动失败问题**。

## 升级方法

1. 从托盘完全退出旧版，避免启动新 EXE 时只唤起旧窗口。
2. 运行 `bilibili-drops-miner-gui-v2.1.1.exe`。
3. 确认标题显示 `v2.1.1`，再使用获取任务 ID 等功能。

在同一电脑、同一 Windows 用户下，已保存的账号和设置可继续使用。
