# BiliDrop v2.1.0 更新说明

## 作者说

谢谢无名介绍这个软件。

2.0 之后没有限制线程数，只是把线程设置移到了右上角“设置与日志”。想长期多线程，
把并发模式改成“固定”后直接填写线程数即可。

Bilibili 的多线程只能追赶直播已经播出的时长，不能提前获得未来时长。v2.1.0 自动模式
单账号从 32 线程开始，多账号每个账号从 16 线程开始。觉得规则麻烦，可以直接点击
“本次 100 线程加速”；线程过高仍可能触发风控，导致进度不计时。

## 主要更新

- “开始”已合并后台自动挂机：同时启动观看和任务检测，不再保留两个重复按钮。
- 全部奖励确认领取后关闭观看线程，只保留后台检测；发现新任务后自动重新开始。
- 如果完成状态误判，再次点击“开始”会强制继续，本次不再自动暂停。
- 自动追赶未达到预期时会降为 2 线程；后台检测到的新任务也会优先使用 2 线程稳定运行。
- 支持多账号独立挂机、进度和设置；“应用到所有账号”可统一操作。
- 任务刷新、领奖和后台检查统一限频，领奖失败会冷却后重试。
- 旧版 Cookie、备注和账号设置可以继续读取，不需要重新登录。

## 升级方法

从 [GitHub Releases](https://github.com/JumpTwiceShou/bilidrop/releases/latest) 下载 v2.1.0
单文件 EXE。先从托盘退出旧版本，再运行新版本；已保存账号和设置会自动保留。

## 使用提醒

多线程不保证一定加速。如果进度停止增长，请降低线程数并等待平台恢复。
