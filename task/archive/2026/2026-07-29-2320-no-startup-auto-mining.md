# 后台自动挂机仅限当前运行

## 目标

- 不停止用户当前已经运行的后台自动挂机。
- 立即把本地保存设置中的启动自动挂机状态改为关闭。
- 后台自动挂机改为会话状态：每次启动程序默认关闭，只有用户本次运行中
  主动点击后才开启。
- 保存普通设置时不再保存后台自动挂机的运行状态。
- 界面小字明确说明重新打开程序后需要手动开启。

## 验收

- [x] 当前挂机进程保持运行
- [x] 本地保存状态已安全关闭且其他设置不变
- [x] 启动加载不会恢复后台自动挂机
- [x] 设置保存不会写入开启状态
- [x] 聚焦测试与新名单文件构建通过

## 限制

- 不提交、不推送、不公开发布。
- 不覆盖或终止用户当前运行的 EXE。
