# 运行按钮与账号作用域开关

## 范围

- 删除“所有账号”独立开始/停止按钮组。
- 当前运行按钮合并为一颗状态按钮：未运行显示“开始”，运行后显示“停止”。
- 后台自动挂机按钮合并为一颗状态按钮：未启用显示“后台自动挂机”，启用后显示“停止后台自动”。
- 在两颗按钮右侧增加 iOS 风格“应用到所有账号”开关。
- 开关关闭时，两颗按钮只操作当前账号；开关开启时，两颗按钮操作全部账号。
- 将开关状态保存到现有加密设置文件，保持旧设置兼容。
- 修复先开启后台自动挂机、后填写房间号/识别任务时仍等待旧轮询时间的问题；
  房间或任务输入变化后立即唤醒对应账号的自动检查。
- 删除运行区“预估观看时长”显示，并停止对应的高频额外查询；任务实际进度
  刷新保持不变。
- “识别当前任务”后台识别失败后自动启动可见浏览器任务抓取兜底，不再额外
  弹窗询问；房间号的浏览器获取功能保持独立。
- 检查自动并发在运行一段时间后未降到 2 的判定链路；界面明确显示当前
  实际/目标会话数和自动并发所处阶段，避免后台已调整但用户不可见。
- 新账号默认使用自动并发；旧版隐式写入的固定默认值一次性迁移为自动。
  新版明确保存为固定并发后继续保持固定模式。
- 默认并发数和自动追赶并发改为 16。自动模式以 3 分钟为一轮：进度增量
  达到 16 时继续追赶，否则降到 2，并保持到识别出下一组新任务。后台
  自动检测到刚开始且初始进度为 0 的任务直接使用 2；没有可靠开始时间
  的手动启动先用 16 完成首轮检测。
- “停止后台自动”同时停止由后台自动功能启动的挂机，但不误停用户手动
  启动的挂机。
- 更新小字说明、测试、渲染检查和新的单文件 EXE。

## 不做

- 不改变任务识别、领奖、并发算法和账号档案数据。
- 不停止或覆盖用户当前运行的旧程序。
- 不提交、推送或公开发布。

## 验收标准

- 运行区只显示两颗动作按钮和一个账号作用域开关。
- 两颗按钮均在动作成功后原位切换为停止状态，不再并排显示开始/停止。
- 作用域开关同时控制普通挂机和后台自动挂机。
- 后台自动挂机已开启时，随后输入房间号或识别出任务会立即开始检查。
- 切换账号后按钮正确反映当前作用域内的运行/自动挂机状态。
- 聚焦测试和离屏渲染检查通过，并生成不覆盖旧文件的新单文件程序。
- 自动并发能根据任务进度相对现实时间的增长速度降到 2，并在运行区明确显示。
- 停止后台自动后，其自动启动的心跳进程一并停止。
